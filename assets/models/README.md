# Models

These `.rbxm` files are Roblox model exports. Import them into your place via **Studio → Model tab → Insert from File**, or reference them in the Workspace directly.

| File                  | Description                        |
|-----------------------|------------------------------------|
| `Classic_House.rbxm`  | Main house structure               |
| `Parts.rbxm`          | Miscellaneous decorative parts     |
| `walls.rbxm`          | Wall/boundary parts                |
| `Spawn_Location.rbxm` | Player spawn point                 |
| `Export.gltf`         | GLTF mesh export (for reference)   |
